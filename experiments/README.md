# Experiments and Earlier Approaches

These projects are preserved to document the hackathon development journey.
They are useful references, but are not required by the final Python UCP server
and client scripts.

## `tervicke-shop`

A Next.js storefront and agent-commerce prototype exploring UCP discovery,
`agents.md`, a composable MCP endpoint, catalog access, and agent authentication.

## `commerce-sdk`

A TypeScript workspace that explored reusable, transport-independent commerce
domains and a composable MCP server, including identity and authentication.

## `razorpay-checkout`

An early standalone Python/HTML Razorpay Checkout prototype used to validate
the payment flow before integrating it into the UCP merchant server.

## `razorpay-handler-site`

A separate web/Sites prototype for the Razorpay handler experience. It retains
its own Git history because it began as an independent project.

Each experiment retains its original source, configuration templates, and
README where available. Generated dependencies and build caches are ignored.
